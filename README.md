


## 🚀 V5 Production Intelligence

V5 turns the Website Prompt Architect from a prompt generator into a structured website strategy and implementation handoff system.

### New engines

- 🗺️ **Page Architecture Engine** — determines the smallest useful sitemap based on business, user, SEO, and conversion needs.
- 🧩 **Component Architecture** — turns approved sections into reusable implementation components.
- ⚙️ **Intelligent Technology Selection** — evaluates Astro, Next.js, React/Vite, Nuxt, SvelteKit and supporting tools against actual requirements.
- 🛡️ **Anti-Hallucination Content Gate** — prevents invented testimonials, statistics, awards, pricing, clients, claims, and other business facts.
- 🖼️ **Image Art-Direction Engine** — specifies exactly what imagery each page needs and how it should be composed.
- 📊 **Analytics Plan** — defines primary conversion, meaningful events, funnel stages, and measurement questions.
- 🤖 **AI Coding-Agent Handoff** — produces a structured master build prompt for modern coding agents.

### Core V5 principle

> **Ask less. Infer intelligently. Decide explicitly. Output precisely.**

The user still experiences only the four conversational interview rounds. The deeper architecture is handled internally by the skill.
