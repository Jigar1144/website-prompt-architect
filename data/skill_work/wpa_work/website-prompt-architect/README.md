# Website Prompt Architect — Enhanced v4

A business-first website prompt architecture skill with a **4-round adaptive interview**, internal conversion/SEO reasoning, trust/proof inventory, real-world constraint checks, explicit anti-overdesign gates, and an expanded modern web-technology catalog.

### What changed
- 🎯 Four user-facing rounds replace the contradictory 10-step questionnaire.
- 🧠 Internal decision engine still covers 10+ phases without burdening the user.
- 💎 Business differentiation and positioning are first-class inputs.
- 🔥 Customer objections are mapped to design and conversion responses.
- 📍 SEO intent and local SEO intelligence are built into the architecture.
- 🏢 Real-world constraints cover CMS, maintenance, integrations, migration, performance, accessibility, and launch pressure.
- 🛡️ Trust/proof inventory prevents fabricated social proof.
- 🚫 Anti-overdesign gate removes unnecessary effects.
- 📱 Advanced responsive interviewing is removed; normal responsive behavior remains in implementation prompts.
- ⚡ Technology choices now cover Next.js, Astro, React + Vite, Remix/React Router, Nuxt, SvelteKit, GSAP, Motion, Lenis, Three.js, React Three Fiber, WebGL, Spline, PixiJS, Shopify/Hydrogen, modern CMS options, and more.
- ✨ Prompt library is organized with icons, master context, conversion, SEO, trust, constraints, technology, and implementation gates.
