# Reasoning v3 Demo — Ram Builders

INPUT
- Business: Ram Builders
- Type: Residential & commercial construction company
- Goal: Premium home construction leads; enquiry + site visit booking
- Audience: Homeowners and property investors

INFERRED (SAFE)
- Industry: construction-and-property
- Trust model: proof + quality + transparency
- Conversion model: qualified lead
- Visitor intent: evaluate projects + credibility, then contact
- Evidence needed: projects, workmanship/materials, process, proof, enquiry path
- Performance sensitivity: high

NOT INVENTED
- Years in business
- Certifications
- Awards
- Project counts
- Client names
- Pricing
- Guarantees

DESIGN REASONING
- Pattern: Hero + Proof + Projects + Process + CTA
- Style: premium architectural/editorial, restrained rather than trendy
- Motion: moderate, purposeful; avoid heavy 3D unless justified
- CTA: Book a Site Visit
- Secondary CTA: Request a Project Estimate

The system should treat these as inferred decisions, not verified business facts, unless the user confirms them.
