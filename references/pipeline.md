# Website Prompt Architect — Generation Pipeline

## Mode selection

```text
Detailed brief?
YES → Sequential Build Mode
NO  → Adaptive Creative Director Mode
```

## Sequential Build Mode

```text
BRIEF
→ FACT EXTRACTION
→ CONTENT TRUST REGISTER
→ PROJECT SETUP
→ INSTALLATION
→ FOLDER ARCHITECTURE
→ MASTER DESIGN SYSTEM
→ CONTENT / DATA MODEL
→ SHARED COMPONENTS
→ SECTION PROMPTS
→ IMAGE ASSET REGISTRY
→ IMAGE PROMPTS
→ SEO
→ ACCESSIBILITY
→ RESPONSIVE
→ PERFORMANCE
→ MOTION ENHANCEMENT
→ MOTION QA
→ FINAL AGENCY GATE
→ BUILD VERIFICATION
```

## Section generation

Generate one self-contained prompt per approved section.

Every prompt must include:
- objective
- context
- design system
- requirements
- specifications
- responsive behavior
- accessibility
- motion
- assets
- constraints
- acceptance criteria

## Asset pipeline

```text
ART DIRECTION
→ IMAGE ASSET REGISTRY
→ IMAGE PROMPTS
→ GENERATION
→ FILE VALIDATION
→ IMPLEMENTATION
```

Never fabricate asset URLs.

## Motion pipeline

```text
BUSINESS
→ SECTION PURPOSE
→ ART DIRECTION
→ MOTION TIER
→ INTERACTION HIERARCHY
→ PERFORMANCE BUDGET
→ MOTION SELECTION
→ SECTION RECIPES
→ IMPLEMENTATION
→ MOTION QA
```

Do not let the coding model invent unrelated motion for each section.

## Reduced-motion pipeline

Every animated section must define:
- default motion
- mobile motion
- reduced-motion fallback

## Production intelligence

Preserve:
- page architecture
- component architecture
- anti-hallucination content gate
- copywriting/messaging
- SEO
- accessibility/performance
- analytics
- design tokens
- competitive differentiation
- AI coding-agent handoff
