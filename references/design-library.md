# Design Library

This library is a decision aid, not a requirement to use every option.

## Visual styles

### Minimal
Clean hierarchy, low decoration, high clarity.

### Editorial
Large typography, asymmetric composition, strong imagery.

### Industrial Precision
Grid discipline, technical linework, material photography, restrained motion.

### Cinematic
Large imagery, controlled transitions, strong visual storytelling.

### Modern Corporate
Clear proof hierarchy, restrained surfaces, conversion focus.

### Monochrome Luxury
Restrained palette, typography-led hierarchy, minimal accents.

### Command Center
Dark technical surfaces, data/diagram language, high information density.

### Product Showcase
Product-first photography, specification clarity, strong CTA hierarchy.

## Typography pairings

Select according to business identity, not trend popularity.

Always verify:
- licensing
- performance
- readability
- language support

## UX patterns

Use:
- clear navigation
- obvious CTA hierarchy
- resilient content
- accessible forms
- visible focus
- meaningful loading/empty/error states

Avoid:
- hover-only information
- inaccessible custom controls
- unnecessary carousels
- excessive popups
- decorative interaction that competes with conversion
